# Large Address Aware (LAA) executable

Put the LAA-patched `DAOrigins.exe` here. `dao-modman laa patch` and the Tools menu copy it
over `bin_ship/DAOrigins.exe` in the game's install dir, after backing up the original.

The Steam executable cannot simply have the LAA flag flipped in place, which is why a
pre-patched copy is kept in the repository.

The GoG distribution of DAO also includes this modified file, therefore I decided to include it in the repository
and the distributed package.
